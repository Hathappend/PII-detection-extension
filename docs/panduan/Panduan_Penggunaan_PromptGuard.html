🛡️ Panduan Penggunaan PromptGuard

Ekstensi Chrome pendeteksi kebocoran data pribadi (PII) pada prompt AI
Versi 1.1 · 17 Oktober 2026

1. Pengenalan

PromptGuard adalah ekstensi Chrome yang melindungimu dari kebocoran data pribadi saat memakai chatbot AI seperti ChatGPT dan Gemini. Setiap kali kamu mengetik atau menempel prompt, PromptGuard memeriksa apakah ada data pribadi di dalamnya — misalnya NIK, nama, tanggal lahir, atau nomor telepon — lalu memberi peringatan sebelum prompt terkirim.

Seluruh pemeriksaan berjalan 100% di perangkatmu; tidak ada teks prompt yang dikirim ke server mana pun.

Cara kerja singkat

PromptGuard menggabungkan tiga lapisan: pola untuk data berstruktur (NIK, nomor KK, dsb.), model AI (NER) untuk mengenali nama, lokasi, dan tanggal dalam kalimat, serta penilaian risiko yang menggabungkan temuan menjadi empat tingkat peringatan. Detail teknis metode ini didokumentasikan terpisah di dokumen skripsi, bukan di panduan ini.

2. Instalasi

  1. Siapkan folder ekstensi PII-detection-extension di komputermu (hasil mengunduh/clone repositori).
  2. Buka chrome://extensions di Chrome.
  3. Aktifkan Developer mode (sakelar di kanan atas halaman).
  4. Klik Load unpacked, lalu pilih folder PII-detection-extension.
  5. Pastikan Prompting Protection muncul di daftar dan dalam keadaan aktif.
  6. (Opsional) Klik ikon puzzle di toolbar Chrome, lalu pin PromptGuard agar ikonnya selalu terlihat.
  7. Buka chatgpt.com atau gemini.google.com — ekstensi langsung aktif.
Langkah instalasi di atas belum disertai gambar karena halaman chrome://extensions tidak dapat diabadikan di lingkungan penyusunan panduan ini. Kamu bisa menambahkan dua tangkapan layar (tampilan Developer mode dan daftar ekstensi) dari Chrome di komputermu sendiri.

3. Mengunduh Model NER (sekali saja, opsional)

Model NER adalah komponen AI yang mengenali nama, lokasi, dan tanggal dalam kalimat. Model ini diunduh satu kali saja (±110MB), lalu tersimpan di browser.

  1. Klik ikon PromptGuard di toolbar Chrome untuk membuka popup.
  2. Jika model belum diunduh, tampilannya seperti ini — klik ⬇ Download Model NER:
  1. Tunggu proses unduhan selesai. Jangan tutup tab selama mengunduh:
  1. Setelah selesai, status berubah menjadi ✓ Model NER siap:
Catatan: tanpa mengunduh model pun ekstensi tetap berfungsi (memakai pola dan penilaian risiko). Model NER menambah kemampuan mendeteksi nama, lokasi, dan tanggal yang ditulis tanpa pola khusus.

4. Cara Memakai

  • Gunakan ChatGPT atau Gemini seperti biasa: ketik atau tempel prompt ke kolom chat.
  • PromptGuard menganalisis teks secara otomatis setiap kali kamu berhenti mengetik (atau selesai menempel).
  • Jika terdeteksi data pribadi, toast peringatan muncul di bagian atas layar beserta tingkat risikonya.
  • Tidak ada pengaturan yang perlu diubah untuk pemakaian sehari-hari.

5. Arti Tiap Tingkat Peringatan

TingkatTampilanArti & tindakan
Pass Tidak ada peringatan Tidak terdeteksi data pribadi. Prompt aman dikirim.
Warn Toast kuning “Perhatian” Ada indikasi data pribadi ringan. Kamu tetap bisa mengirim, tetapi periksa kembali prompt-mu.
Redact Toast merah “Tunggu Dulu” + tombol Abaikan Data pribadi terdeteksi. Tombol kirim dinonaktifkan dan Enter diblokir. Hapus data tersebut dari prompt, atau klik Abaikan jika kamu sadar akan risikonya.
Block Toast merah “Tidak Bisa Dikirim” Data sangat sensitif terdeteksi. Prompt tidak bisa dikirim sama sekali — hapus datanya terlebih dahulu.

7. Tanya Jawab

Toast tidak muncul padahal saya mengetik data pribadi?
Pastikan kamu berada di chatgpt.com atau gemini.google.com, lalu muat ulang (refresh) halamannya. PromptGuard menganalisis ulang teks yang sudah ada setelah refresh.

Unduhan model NER gagal?
Periksa koneksi internet, buka kembali popup, lalu klik Periksa Ulang dan unduh lagi.

Tombol kirim tetap mati padahal data sudah saya hapus?
Hapus datanya, lalu ketik satu karakter (mis. spasi) agar analisis berjalan ulang. Jika masih bermasalah, muat ulang halaman.

Apakah prompt saya dikirim ke server PromptGuard?
Tidak. Seluruh analisis berjalan lokal di browser-mu, termasuk model NER setelah diunduh.
